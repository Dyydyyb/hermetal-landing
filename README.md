# Hermetal (Bulonera Roca) - Landing Page Oficial

Landing page de alta conversión para **Hermetal** (marca comercial **"Bulonera Roca - Hermetal"**), fabricante nacional de estufas a leña, hornos envolventes, parrillas y metalúrgica industrial en San Luis, Argentina.

---

## 🚀 Características Principales

- **Identidad Corporativa Hermetal:** Naranja corporativo sólido (`#E8622C`), fondo blanco pulido y detalles en acero oscuro (`#0F1115`).
- **100% Imágenes Reales:** Fotografías auténticas de productos Hermetal, fichas técnicas de fábrica (H-20.000, H-14.000, Horno Envolvente), asado familiar y racks industriales.
- **Simulador Interactivo de Estufa:** Fuego dinámico con regulador de tiraje (damper) funcional y sintetizador de sonido crepitante con Web Audio API (cero dependencias externas).
- **Calculador Térmico:** Estimador de metros cuadrados (`m²`) y zona climática para recomendar el modelo de estufa ideal con botón a WhatsApp personalizado.
- **Testimonios Reales:** Formato de reseñas con fotografías reales de clientes y cabañas en San Luis, Potrero de los Funes y Merlo.
- **Lead Generation WhatsApp:** Enlaces directos a WhatsApp para cotización inmediata de fábrica y formulario interactivo.
- **Performance & SEO:** Código semántico HTML5, CSS vanilla con variables de diseño, sin frameworks pesados, 100% responsive.

## 🌐 Deploy en Vercel

Este proyecto está optimizado y listo para ser desplegado en **Vercel** en 1 clic:

### Opción 1: Con GitHub (Recomendada)
1. Subí este repositorio a tu cuenta de GitHub:
   ```bash
   git remote add origin https://github.com/TU-USUARIO/hermetal-landing.git
   git branch -M main
   git push -u origin main
   ```
2. Entrá a [Vercel](https://vercel.com/) y hacé clic en **"Add New Project"**.
3. Seleccioná el repositorio importado. Vercel detectará automáticamente que es un proyecto estático (`Other` / `Static Site`) con el archivo `vercel.json` incluido.
4. Hacé clic en **"Deploy"**.

### Opción 2: Desde la consola con Vercel CLI
```bash
npx vercel
```
